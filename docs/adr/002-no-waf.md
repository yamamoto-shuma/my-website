# ADR-004: WAFを導入しない

## ステータス

Accepted

## コンテキスト

CloudFrontにはAWS WAF（Web Application Firewall）を関連付けることができる。WAFはSQLインジェクション・XSS・ボット対策・レートリミット等のL7レベルの保護を提供する。

今回構築するサイトの特性は以下の通り。

- 純粋な静的HTMLの配信のみ（データベース・API・認証なし）
- 個人サイトであり、攻撃対象となる機密情報や機能を持たない
- AWS Shield Standard（無料）がCloudFrontに標準付帯している

## 決定

**WAFを導入しない。**

## その他の選択肢にしなかった理由

- **AWS WAF（マネージドルール）**: 月額約$5〜のコストが発生する。静的HTMLサイトに対してSQLインジェクションやXSSの保護は不要であり、費用対効果が見合わない
- **AWS WAF（カスタムルール）**: レートリミット等の設定は可能だが、個人サイトの規模では過剰な設定となる

## 結果

**ポジティブ:**
- WAFのコスト（月額固定費）が不要
- 設定・運用の複雑さを排除できる

**ネガティブ:**
- L7レベルの大量リクエストによるコスト攻撃リスクが残る。ただしAWS Shield Standard（無料・標準付帯）によりL3/L4 DDoSは保護される
- サイトの性質が変わった場合（認証・APIの追加等）は本決定を見直す必要がある

## 再検討トリガー

以下の条件に該当する場合は本ADRを見直すこと。

- サイトにAPIや認証機能を追加する場合
- 異常なトラフィックによるコスト増加が発生した場合
