## ADDED Requirements

### Requirement: 日付ページでその日のアクティビティを表示する
`/garmin/:date` でその日に記録された Garmin アクティビティをカード形式で表示する。複数アクティビティに対応する。アクティビティデータは読み取り専用で編集不可。

#### Scenario: アクティビティが存在する場合
- **WHEN** ユーザーが日付ページを開く
- **THEN** システムはその日のアクティビティをカード一覧で表示する（種別ごとに主要指標を表示）

#### Scenario: 複数アクティビティが存在する場合
- **WHEN** 1 日に複数のアクティビティが記録されている
- **THEN** システムはすべてのアクティビティをカード形式で縦に並べて表示する

#### Scenario: アクティビティがない場合
- **WHEN** その日にアクティビティが存在しない
- **THEN** システムは「表示するアクティビティがありません」と表示する

#### Scenario: データ取得失敗
- **WHEN** Garmin API またはキャッシュからのデータ取得に失敗する
- **THEN** システムは「データの取得に失敗しました」と表示する

### Requirement: アクティビティカードに種別に応じた主要指標を表示する

スイムカードには距離・時間・SWOLF・ストロークレート・心拍数を表示する。
バイクカードには距離・時間・平均速度・ケイデンス・獲得標高・心拍数・TE（Training Effect）を表示する。
ランカードには距離・時間・平均ペース・ケイデンス・VO2Max・心拍数・TE（Training Effect）を表示する。

#### Scenario: スイムカード表示
- **WHEN** スイムのアクティビティカードが表示される
- **THEN** 距離・時間・SWOLF・ストロークレート・心拍数が表示される

#### Scenario: バイクカード表示
- **WHEN** バイクのアクティビティカードが表示される
- **THEN** 距離・時間・平均速度・ケイデンス・獲得標高・心拍数・TE が表示される

#### Scenario: ランカード表示
- **WHEN** ランのアクティビティカードが表示される
- **THEN** 距離・時間・平均ペース・ケイデンス・VO2Max・心拍数・TE が表示される

### Requirement: good / problem / others のノートを記録・閲覧できる
その日のトレーニングに関する振り返りを 3 つのフィールドで記録できる。

#### Scenario: ノートの閲覧（デフォルト）
- **WHEN** ユーザーが日付ページを開く
- **THEN** good / problem / others の内容が閲覧モードで表示される（空の場合は空欄）

#### Scenario: 編集モードへの切り替え
- **WHEN** ユーザーが「編集」ボタンを押す
- **THEN** good / problem / others の 3 フィールドが同時に編集可能になり、保存・キャンセルボタンが表示される

#### Scenario: ノートの保存
- **WHEN** ユーザーが内容を編集して「保存」ボタンを押す
- **THEN** システムはノートを保存し閲覧モードに戻る

#### Scenario: 編集のキャンセル
- **WHEN** ユーザーが「キャンセル」ボタンを押す
- **THEN** システムは変更を破棄し閲覧モードに戻る

### Requirement: AI 分析を手動で生成・表示できる
アクティビティとノートをもとにトライアスロントレーナーとしての AI アドバイスを生成できる。

#### Scenario: 未生成状態の表示
- **WHEN** AI 分析がまだ生成されていない
- **THEN** 「分析を生成」ボタンが表示される

#### Scenario: AI 分析の生成
- **WHEN** ユーザーが「分析を生成」ボタンを押す
- **THEN** システムは Gemini API を呼び出し、結果を DynamoDB に保存して画面に表示する

#### Scenario: 生成済み分析の表示
- **WHEN** AI 分析が保存済みの状態でページを開く
- **THEN** 保存済みの分析結果を表示する（API 呼び出しなし）

#### Scenario: 再分析
- **WHEN** AI 分析が表示されている状態でユーザーが「再分析」ボタンを押す
- **THEN** システムは Gemini API を再度呼び出し、結果を上書き保存して画面を更新する

### Requirement: AI 分析はアクティビティデータとノートおよびプロフィールを文脈として使用する
AI はトライアスロントレーナーとしての役割で以下のアドバイスを含む回答を生成する。

- problem に記載された内容の改善方法
- others に記載された疑問への回答
- アクティビティ数値へのコメント（良い点・改善の余地）
- ネクストアクションの提案

#### Scenario: プロフィール未登録時の AI 分析
- **WHEN** プロフィールが未登録の状態で AI 分析を生成する
- **THEN** システムはプロフィールなしの文脈でアドバイスを生成する（エラーにならない）

#### Scenario: プロフィール登録済み時の AI 分析
- **WHEN** プロフィールが登録済みの状態で AI 分析を生成する
- **THEN** システムはプロフィール情報（目標レース・現在の実力値）を文脈に含めた詳細なアドバイスを生成する
