## ADDED Requirements

### Requirement: デザイントークンを CSS カスタムプロパティで一元管理する
`src/styles/garmin-tokens.css` にカラー・タイポグラフィのトークンを定義し、全 Garmin ページコンポーネントから参照する。Garmin Connect 公式アプリの配色（純黒背景・Garmin Blue・アクティビティ種別カラー）を踏襲する。

#### Scenario: トークンファイルの存在
- **WHEN** `src/styles/garmin-tokens.css` が存在する
- **THEN** カラートークン（`--color-bg`, `--color-surface`, `--color-primary` 等）がすべて定義されている

#### Scenario: Garmin ページ全体に適用
- **WHEN** `/garmin` 配下のページが表示される
- **THEN** 背景色は `#000000`（純黒）で描画される

### Requirement: ページ背景は純黒、カード背景は `#1A1A1A` とする
Garmin Connect 公式アプリと同一の階層的ダーク背景を使用する。

#### Scenario: カレンダーページの背景
- **WHEN** `/garmin` カレンダーページが表示される
- **THEN** ページ背景は `#000000`、日付グリッドのセルは `#1A1A1A` 系で描画される

#### Scenario: 日付ページの背景
- **WHEN** `/garmin/:date` ページが表示される
- **THEN** ページ背景は `#000000`、アクティビティカードとノートセクションは `#1A1A1A` で描画される

### Requirement: アクティビティカードのアクセントカラーは種別で異なる
各アクティビティ種別に対応するカラーで視覚的に区別できるようにする。

#### Scenario: ランアクティビティカードのカラー
- **WHEN** ランのアクティビティカードが表示される
- **THEN** カード上部またはアクセントにオレンジグラデーション（`#E8921A` → `#F5A623`）が適用される

#### Scenario: スイムアクティビティカードのカラー
- **WHEN** スイム（プールスイム）のアクティビティカードが表示される
- **THEN** カード上部またはアクセントに `#2B9DF5`（Garmin Blue）が適用される

#### Scenario: バイクアクティビティカードのカラー
- **WHEN** バイクのアクティビティカードが表示される
- **THEN** カード上部またはアクセントに `#FF8C00`（アンバー）が適用される

### Requirement: 主要メトリクス値は大きなフォント（48px Bold）で表示する
距離・心拍・ペースなどの数値は視認性を最優先した表示にする。Garmin Connect と同様に数値を最も目立つ要素とする。

#### Scenario: アクティビティカードのメトリクス値
- **WHEN** アクティビティカードが表示される
- **THEN** 主要メトリクス（距離など）は 48px Bold の白テキストで描画される
- **THEN** メトリクスのラベルは 12px の `#9E9E9E` テキストで描画される

### Requirement: インタラクティブ要素は Garmin Blue（`#2B9DF5`）を使用する
ボタン・アイコン・アクティブ状態などのインタラクティブ要素は統一して Garmin Blue を使用する。

#### Scenario: プライマリボタンの配色
- **WHEN** 「分析を生成」などのプライマリボタンが表示される
- **THEN** ボタン背景は `#2B9DF5`、テキストは `#FFFFFF` で描画される

#### Scenario: アウトラインボタンの配色
- **WHEN** 「編集」「再分析」などのアウトラインボタンが表示される
- **THEN** ボタンのボーダーとテキストは `#2B9DF5` で描画される

### Requirement: メトリクスは 2 列グリッドで区切り線区切りで表示する
アクティビティカードのメトリクス一覧は Garmin Connect と同様に 2 列グリッド + 水平区切り線のレイアウトとする。

#### Scenario: メトリクスグリッドのレイアウト
- **WHEN** アクティビティカードのメトリクスエリアが表示される
- **THEN** 補助指標は 2 列で並び、各行の間に `#2C2C2E` の水平区切り線が表示される

### Requirement: テキストは白（プライマリ）とグレー（セカンダリ）の 2 色のみ使用する
テキストカラーは `#FFFFFF` と `#9E9E9E` の 2 色に統一し、ダーク背景との視認性を確保する。

#### Scenario: セカンダリテキストの色
- **WHEN** メトリクスラベル・日付・補足情報が表示される
- **THEN** これらのテキストは `#9E9E9E` で描画される
