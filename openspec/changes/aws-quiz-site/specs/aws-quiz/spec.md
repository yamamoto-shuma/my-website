## ADDED Requirements

### Requirement: サービス選択画面が表示される
ユーザーはクイズ開始前にPhaseおよびサービスでフィルタリングできなければならない（SHALL）。選択した条件に一致する問題のみが出題されなければならない（SHALL）。

#### Scenario: Phaseで絞り込む
- **WHEN** ユーザーがPhase1を選択して開始ボタンを押す
- **THEN** Phase1に属するサービス（VPC・IAM・KMS）の問題のみが出題される

#### Scenario: サービスで絞り込む
- **WHEN** ユーザーが「VPC」のみを選択して開始ボタンを押す
- **THEN** VPCの問題のみが出題される

#### Scenario: 問題がない条件で開始しようとする
- **WHEN** 問題が0件になる条件を選択している
- **THEN** 開始ボタンが無効化され、クイズを開始できない

### Requirement: 4択形式で問題が出題される
各問題は問題文と4つの選択肢で構成されなければならない（SHALL）。ユーザーが選択肢を選ぶと即座に正誤と解説が表示されなければならない（SHALL）。

#### Scenario: 正解を選択する
- **WHEN** ユーザーが正解の選択肢をクリックする
- **THEN** 正解であることが視覚的に示され、解説が表示される

#### Scenario: 不正解を選択する
- **WHEN** ユーザーが不正解の選択肢をクリックする
- **THEN** 不正解であることが示され、正解の選択肢と解説が表示される

#### Scenario: 回答後に次の問題へ進む
- **WHEN** 解説が表示された状態で「次へ」ボタンを押す
- **THEN** 次の問題が表示される。最後の問題の場合は結果画面に遷移する

### Requirement: 結果画面で採点結果が確認できる
全問回答後に正解数・正答率・サービス別の正解率が表示されなければならない（SHALL）。

#### Scenario: 結果画面が表示される
- **WHEN** 全問回答が完了する
- **THEN** 正解数・正答率・サービス別内訳が表示される

#### Scenario: もう一度挑戦できる
- **WHEN** 結果画面で「もう一度」ボタンを押す
- **THEN** 同じ条件で問題が出題される（問題順はシャッフル）
