# ゴール
- Phase1（VPC・IAM・KMS）の問題データが作成されており、クイズサイトで出題できる
- 各サービス10〜15問、実務レベルの内容になっている

# やること
- VPC の問題を作成する（10〜15問）
  - サブネット設計、ルートテーブル、セキュリティグループ vs NACL、VPC Peering、NAT Gateway、Flow Logs など
- IAM の問題を作成する（10〜15問）
  - 最小権限原則、ロール vs ユーザー、信頼ポリシー、サービスロール、Permission Boundary など
- KMS の問題を作成する（10〜15問）
  - CMK 管理、エンベロープ暗号化、各サービスとの連携、キーポリシーなど
- 各問題に解説（explanation）を含める
- `src/data/questions/` に `vpc.json`・`iam.json`・`kms.json` として配置する
- ローカルで問題が正しく表示・採点されることを確認する
