# ゴール
- React + Vite + TypeScript のプロジェクトがサイト全体として構築されている
- `npm run build` でビルドした成果物が `dist/` に出力される
- GitHub Actions の deploy ワークフローにビルドステップが追加され、デプロイ元が `./dist` に変更されている
- 既存の `public/index.html` が React コンポーネントとして移行されており、`public/` ディレクトリが削除されている

# やること
- `npm create vite@latest` で React + TypeScript プロジェクトを初期化する（Node.js 24 LTS）
- `vite.config.ts` で `publicDir: 'static'`、`build.outDir: 'dist'` を設定する
- `.gitignore` に `dist/` を追加する
- `.github/workflows/deploy.yml` に以下を追加・変更する
  - Node.js 24 セットアップ（`cache: 'npm'` でキャッシュ有効化）
  - `npm ci`・`npm run build` ステップを追加
  - sync元を `./public` から `./dist` に変更
- 既存の `public/index.html` を `src/pages/Home.tsx` に移行し、`public/` ディレクトリを削除する
- React Router を設定し、`/` → `Home`、`/aws-quiz` → `AwsQuiz` のルーティングを実装する
- `npm run build` でビルドが正常に完了し、`dist/` に成果物が出力されることをローカルで確認する
