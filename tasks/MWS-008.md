# ゴール
- React + Vite + TypeScript のプロジェクトが `src/` ディレクトリに構築されている
- `npm run build` でビルドした成果物が `public/aws-quiz/` に出力される
- GitHub Actions の deploy ワークフローにビルドステップが追加されており、mainマージ時に自動デプロイされる

# やること
- `npm create vite@latest` で React + TypeScript プロジェクトを初期化する
  - ソースコードは `src/` に配置
  - `vite.config.ts` で `build.outDir` を `public/aws-quiz` に設定
- `.gitignore` に `public/aws-quiz/` と `node_modules/` を追加する
- `.github/workflows/deploy.yml` にビルドステップを追加する
  - `npm ci`
  - `npm run build`
- ローカルで `npm run build` を実行してビルドが通ることを確認する
- `https://yama-shu.com/aws-quiz/` にアクセスしてデプロイが確認できることを確認する
