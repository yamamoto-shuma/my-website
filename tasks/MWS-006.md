# ゴール
- `/aws-quiz/` などサブディレクトリのURLにアクセスしたとき、`index.html` が自動的に返される

# やること
- CloudFront Function を作成し、以下のルールでリクエストパスを書き換える
  - パスが `/` で終わる場合 → 末尾に `index.html` を付与（例: `/aws-quiz/` → `/aws-quiz/index.html`）
  - パスに拡張子がない場合 → 末尾に `/index.html` を付与（例: `/aws-quiz` → `/aws-quiz/index.html`）
  - 拡張子がある場合（`.html`, `.css`, `.js` 等）→ そのまま
- CloudFront Distribution の viewer request に CloudFront Function を関連付ける
- `terraform plan` / `terraform apply` を実行してリソースを作成する
- `https://yama-shu.com/aws-quiz/` および `https://yama-shu.com/aws-quiz` にアクセスしてページが表示されることを確認する
