# ゴール
- クイズサイトの全画面（サービス選択・問題出題・結果表示）が動作する
- Phase・サービス別のフィルタリングが機能する
- 問題データ（JSON）のスキーマが確定しており、MWS-010での問題追加に対応できる

# やること
- 問題データのスキーマを定義する（`src/types/quiz.ts`）
  - フィールド: id, phase, service, question, choices（4択）, answer, explanation
- コンポーネントを実装する
  - `ServiceSelector.tsx` : Phase・サービス別フィルタリング + 開始ボタン
  - `QuizCard.tsx` : 問題文・4択選択肢・解説表示
  - `Result.tsx` : 正解数・正答率・サービス別内訳表示
- `src/data/questions/` にダミー問題データ（各サービス1問）を用意してローカル動作確認する
- ローカルで全画面の動作を確認する（`npm run dev`）
